# Security Policy

## Reporting a Vulnerability

SONIC-A3 is an independent, unofficial research derivative. It is not an
NVIDIA or Zhiyuan Robotics product, and its maintainers do not represent those
organizations.

Report a vulnerability in this repository through GitHub's private
[security-advisory form](https://github.com/ytzdolp/SONIC-A3-public/security/advisories/new).
Do not include credentials, private robot addresses, proprietary models, or
unreleased datasets in a public issue.

If the vulnerability is demonstrably in the unchanged NVIDIA upstream rather
than this derivative, also follow the upstream project's own security policy.
