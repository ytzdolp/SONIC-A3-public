# Third-party source and public release scope

Updated: 2026-10-14

This document records the boundary between the private experiments and the
contents of the public SONIC-A3 repository.

## Recorded facts

1. The A3 walking controller used as a teacher was obtained through a
   legitimate project channel and was used in private experiments.
2. This repository does not distribute the controller, deployment
   configuration, numerical contract, rollouts, training data, telemetry, or
   related model weights.
3. This project does not represent vendor endorsement. Access to the controller
   does not by itself establish permission to redistribute every derived
   dataset, checkpoint, or other artifact.

## Public repository boundary

The public repository contains independently written integration and training
code together with bounded, self-reported experimental records. Before any
third-party or controller-derived artifact is added, its applicable publication
and redistribution terms must be checked separately. Confidential source or
permission records should remain outside Git; only a non-confidential scope
summary should be recorded here.
