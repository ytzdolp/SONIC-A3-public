# Contributing

Contributions are welcome through the
[SONIC-A3-public repository](https://github.com/ytzdolp/SONIC-A3-public).
Before submitting a change, follow [the contribution guide](https://github.com/ytzdolp/SONIC-A3-public/blob/main/CONTRIBUTING.md) and do not include
robot assets, external-policy files, checkpoints, rollouts, credentials, or
other material without documented redistribution rights.
