# Support

For SONIC-A3 questions and issues, use the
[SONIC-A3-public issue tracker](https://github.com/ytzdolp/SONIC-A3-public/issues).

SONIC-A3 is an independent derivative. Its maintainers do not provide support
on behalf of NVIDIA or Zhiyuan Robotics. For a problem reproducible in
unchanged upstream SONIC, use the upstream project's own support channel.
